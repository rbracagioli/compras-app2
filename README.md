# App de Compras Gastronômico

App simples para racionalizar a compra de insumos em estabelecimentos gastronômicos.

## Funcionalidades

- Lista do dia agrupada por fornecedor
- Autocomplete de insumos com busca por texto
- Cadastro de insumos sem fornecedor definido
- Dashboard com resumo semanal e concentração por fornecedor
- Geração de rota otimizada via Google Maps
- Histórico de compras com agrupamento por data
- Alertas de insumos atrasados baseados em frequência histórica

## Como usar

Acesse: **https://rbracagioli.github.io/compras-app**

Ou abra o `index.html` direto no navegador do celular.

## Publicação no GitHub Pages

1. Crie um repositório no GitHub (ex: `compras-app`)
2. Faça upload dos arquivos desta pasta
3. Vá em **Settings → Pages**
4. Em *Source*, selecione `Deploy from a branch`
5. Escolha branch `main`, pasta `/ (root)`
6. Clique **Save** — em ~1 minuto o app estará publicado

## Dados

Os dados ficam salvos no `localStorage` do navegador. Nenhuma informação sai do dispositivo.
